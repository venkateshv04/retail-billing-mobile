# Maanas Shop - Android phone app

This repository holds only the **releases** of the Maanas Shop phone app (the APK files). It holds no code.

## Install on a phone

1. Open **Releases** (on the right) and download `maanas-shop-<version>.apk` on the Android phone.
2. Open the downloaded file. If Android asks, allow "Install unknown apps" for the app you opened it from.
3. Tap **Install**.

Sign-in works only for Google accounts that the shop has allowed.

## Updates

The app checks this page by itself when it opens. When a newer version is here, it shows a message with a button:
the button downloads the new APK, checks it, and opens Android's install screen. Tap **Install** there. The app's
sign-in and settings are kept.

Each release also has `maanas-shop-<version>.apk.sha256`, the fingerprint of the APK, so a damaged or changed
download can be recognised.
